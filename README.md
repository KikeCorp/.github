# KikeCorp — Configuration de l’organisation

Ce dépôt centralise les éléments de configuration publique de l’organisation GitHub **KikeCorp**.

Il permet notamment de gérer :

- **Le profil public** de l’organisation, affiché sur sa page GitHub.
- **Les fichiers communautaires** partagés entre les dépôts.
- **Les modèles de contribution** et de documentation, le cas échéant.

## Présentation

KikeCorp est un espace personnel consacré aux systèmes, aux infrastructures et aux technologies.

Les projets, scripts et expérimentations sont publiés et documentés au fil des besoins.

**Site web :** https://kikecorp.eu/
